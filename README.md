# Vertical Garden Website

This project is a React-based website for showcasing vertical gardening solutions. It includes various pages such as Home, About, Services, Products, Portfolio, Blog, and Contact.

## Project Structure

```
verticalgarden-website
├── src
│   ├── index.tsx          # Entry point of the application
│   ├── App.tsx            # Main application component with routing
│   ├── pages              # Contains all the page components
│   │   ├── Home.tsx       # Homepage content
│   │   ├── About.tsx      # Information about the website/company
│   │   ├── Services.tsx   # List of services offered
│   │   ├── Products.tsx    # Showcases available products
│   │   ├── Portfolio.tsx   # Displays past projects or works
│   │   ├── Blog.tsx       # Lists blog posts or articles
│   │   └── Contact.tsx    # Contact form or information
│   ├── components         # Reusable components
│   │   ├── Header.tsx     # Navigation menu and branding
│   │   ├── Footer.tsx     # Copyright and additional links
│   │   ├── Hero.tsx       # Prominent section on the homepage
│   │   ├── ServicesList.tsx # Renders a list of services
│   │   ├── ProductCard.tsx # Displays individual product information
│   │   └── ContactForm.tsx # Handles user input for contacting
│   ├── styles             # CSS styles
│   │   ├── globals.css    # Global CSS styles
│   │   └── variables.css   # CSS variables for consistent styling
│   └── types              # TypeScript type definitions
│       └── index.d.ts     # Type definitions used throughout the project
├── public
│   └── robots.txt         # Instructions for web crawlers
├── package.json           # npm configuration file
├── tsconfig.json          # TypeScript configuration file
├── .gitignore             # Files and directories to ignore by Git
└── README.md              # Documentation for the project
```

## Getting Started

1. Clone the repository:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd verticalgarden-website
   ```

3. Install dependencies:
   ```
   npm install
   ```

4. Start the development server:
   ```
   npm start
   ```

## Features

- Responsive design for various devices
